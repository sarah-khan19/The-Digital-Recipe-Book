# The Digital Recipe Book

Personalized website that was designed to showcase and keep track of baking recipes. Built from Figma wireframes with HTML, CSS, and JavaScript only.

## Open locally

```bash
cd digital-recipe-book
python3 -m http.server 8080
```

Then visit http://localhost:8080/

Or open `digital-recipe-book/index.html` directly in a browser (the repo root `index.html` redirects there).

## Pages

- Home — `digital-recipe-book/index.html`
- All Recipes — `digital-recipe-book/all-recipes.html`
- Recipe pages under `digital-recipe-book/recipes/`
  - Chocolate Brownies
  - Chocolate Chip Cookies
  - Banana Bread
  - Lemon Poppyseed Loaf
  - Banana Crumble Muffins
  - Funnel Cake (strawberry compote ingredient links to its recipe)
  - Chocolate Chip Muffins
  - Strawberry Compote
  - Chocolate Ganache

Assets are exported from the Figma file and live under `digital-recipe-book/assets/`.
